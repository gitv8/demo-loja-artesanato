# demo-loja-artesanato
Loja virtual completa em HTML, CSS e JavaScript (simulação). Inclui vitrine, detalhes de produto e carrinho totalmente funcional no front-end.

## 🛍️🛒 Demo de Loja Virtual

Demonstração de uma interface de e-commerce construída com HTML, CSS, Bootstrap e JavaScript, totalmente funcional no front-end.

🔍Link para visualização: 
<a href="https://gitv8.github.io/demo-loja-artesanato/">🔗https://gitv8.github.io/demo-loja-artesanato/</a>

O projeto apresenta:

- Vitrine de produtos com navegação e carrossel
- Página de detalhes com informações e variações
- Carrinho de compras com cálculo automático de valores
- Controle de navegação apenas no JavaScript
- Código estruturado e fácil de expandir

Esta demonstração serve como vitrine de interface e experiência de uso, podendo ser integrada a backend e meios de pagamento conforme a necessidade.
